# YT Music In-Game (Fabric, Minecraft 1.21.11)

YouTube Music прямо в Minecraft: окно с настоящим music.youtube.com (встроенный Chromium через мод Rinku).
Вход в аккаунт, поиск, плейлисты, очередь — всё как в обычном браузере. Окно можно двигать, менять размер,
прятать (музыка продолжает играть), управлять паузой/треками/громкостью.

## Что нужно в папке mods
1. Fabric API (для 1.21.11)
2. Rinku 3.0.1 для 1.21.11 Fabric (тот jar, который ты скачал на Modrinth)
3. ytmusic-ingame-1.2.0.jar (этот мод, после сборки)

При первом запуске Rinku скачает Chromium (~200 МБ) — подожди, пока закончит.

## Управление (все клавиши меняются в Настройки → Управление → YT Music)
| Клавиша | Действие |
|---|---|
| Y | открыть окно плеера |
| U | оверлей: выкл → полоска → карточка с обложкой → полный → выкл |
| K | переместить оверлей в следующий угол экрана (правый верх → правый низ → левый низ → левый верх) |
| \ | пауза / пуск |
| [ и ] | предыдущий / следующий трек |
| = и - | громкость + / − |
| M | выключить звук |

В окне плеера:
- тащи за верхнюю полосу — перемещение (хоть в любой угол);
- тащи правый нижний угол — размер;
- кнопка **HUD: off / bar / card / full** — что останется на экране после закрытия окна:
  off — ничего; bar — тонкая плашка «сейчас играет»; **card — маленькая карточка с обложкой трека сбоку**,
  названием, исполнителем, временем и полосой прогресса; full — сама страница плеера;
- нижняя панель: ⏮ ⏯ ⏭, значок динамика (mute), ползунок громкости (колёсико над панелью тоже меняет громкость),
  полоса прогресса сверху панели (клик/перетаскивание = перемотка), `-` `+` масштаб страницы, `Home`;
- ESC или кнопка `x` — закрыть окно. Музыка продолжает играть.

## Оверлей и чат
Пока окно плеера закрыто, оверлей просто висит на экране (bar / card / full) и не мешает игре.
**Когда ты открываешь чат (T), оверлей становится интерактивным** — курсор свободен, и можно:
- **перетаскивать оверлей мышкой куда угодно** (зажми карточку / полоску / верхнюю полосу окна);
- нажимать кнопки ⏮ ⏯ ⏭ на карточке, кликать по полосе прогресса (перемотка), крутить колёсико над оверлеем (громкость);
- в режиме **full** работать с самой страницей YouTube Music мышкой: выбирать песни и плейлисты, листать,
  менять размер окна за правый нижний угол, кнопка `x` скрывает оверлей.

Что нужно знать:
- В чате клавиатура остаётся у строки чата, поэтому **печатать в поиске YT Music из чата нельзя** — для этого открой окно клавишей Y.
- Клик по оверлею доходит и до чата под ним — поставь оверлей подальше от текста чата (левый нижний угол обычно занят чатом, лучше правый верхний).
- Колёсико над оверлеем крутит громкость (или страницу в режиме full), а не историю чата.

### Размер, зеркалирование, бегущая строка
- **Размер полоски/карточки:** в чате **Ctrl + колёсико** над оверлеем или тяни **ручку в нижнем углу**
  (точки на внутренней стороне). Край у границы экрана остаётся на месте. Диапазон 50%–300%, сохраняется в `miniScale`.
- **Зеркалирование:** если перетащить оверлей на левую половину экрана, он разворачивается к левому краю —
  полоса-акцент, обложка, кнопки и блок текста меняются местами. Текст и иконки при этом не отражаются.
- **Бегущая строка:** длинное название трека плавно уезжает влево и снова выезжает с начала
  (в полоске, карточке и в заголовке окна плеера). Короткое стоит на месте.

### Стиль: Minecraft или модерн
Кнопка **MC / Modern** в заголовке окна плеера (или своя клавиша в Управление → YT Music, по умолчанию не назначена).
Модерн — гладкий шрифт Inter, скруглённые окна, круглые кнопки, сглаженные иконки и обложка со скруглёнными углами.
Шрифт лежит в `assets/ytmusic/font/` (лицензия OFL, файл `OFL-Inter.txt`); символы, которых в нём нет
(например, японские), берутся из обычного шрифта Minecraft.
Если шрифт кажется мелким/крупным — поменяй `size` в `assets/ytmusic/font/modern.json`.

## Как войти в аккаунт
Открой окно (Y) → в YT Music нажми **Sign in** → войди как в обычном браузере.
Сессия сохраняется между запусками (Rinku хранит данные браузера).
Если Google пишет «браузер небезопасен» — см. раздел «Проблемы».

## Сборка

### Вариант А (если у тебя уже стоит JDK 21 и IntelliJ IDEA)
1. Открой папку проекта в IntelliJ IDEA (File → Open), дождись загрузки Gradle.
2. Справа вкладка Gradle → Tasks → build → **build**.
3. Готовый файл: `build/libs/ytmusic-ingame-1.2.0.jar` (без `-sources`).
Для теста прямо из IDE: Tasks → fabric → **runClient**.

### Вариант Б (самый надёжный, если Gradle ругается на версии)
1. На https://fabricmc.net/develop/template/ сгенерируй шаблон: Minecraft 1.21.11, Yarn, любое имя мода.
2. Удали из шаблона папку `src`, скопируй вместо неё `src` из этого проекта.
3. В `build.gradle` шаблона добавь блоки `repositories { exclusiveContent {...} }` и строку
   `modImplementation "maven.modrinth:bQhBuv7x:zs7w62AF"` из моего `build.gradle`.
4. Собери `gradlew build`.

## Настройки
Файл `.minecraft/config/ytmusic.json`: позиция/размер окна, громкость, режим оверлея, масштаб страницы,
стартовый URL, `spoofUserAgent`, `miniX` / `miniY` / `miniW` / `miniScale` (позиция, ширина и масштаб полоски/карточки),
`style` (`CLASSIC` / `MODERN`), `activeFps` / `idleFps` (когда окно скрыто, браузер рисует с низкой частотой кадров).

## Проблемы
- **Google блокирует вход.** Мод представляет встроенный Chromium как обычный Chrome (`spoofUserAgent: true`).
  Если не помогло — в `ytmusic.json` попробуй свой `userAgent`, перезапусти игру. Гарантировать вход я не могу:
  Google иногда блокирует встроенные браузеры независимо от настроек.
- **Громкость скачет до 100%.** Исправлено в 1.2.0: страница больше не может сама менять громкость —
  любая её попытка сразу превращается в громкость мода.
- **Нет звука.** Звук идёт напрямую из Chromium в систему, а не через ползунки громкости Minecraft.
  Проверь громкость в Windows (микшер) и ползунок в плеере.
- **Окно серое / «Chromium is still downloading».** Rinku ещё скачивает или запускает Chromium. Подожди.
- **Ошибка при сборке.** Пришли мне текст ошибки целиком — исправлю.

## Как это работает (для справки)
Мод открывает music.youtube.com в Chromium и управляет им маленькими JavaScript-вставками (пауза, трек, громкость).
Состояние (название, играет/пауза, время) возвращается через сообщения консоли страницы.
Никакие аудиопотоки не вытаскиваются и YouTube не обходится — используется обычный веб-плеер.
